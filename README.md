# Network Automation Tools Registry

This repository contains the spec and implementation scaffolding for a spec-driven Automation Tools Database: a normalized registry of network automation tools, their versions, capabilities, integrations, dependencies, and per-environment install instructions. The authoritative design and API contract are defined in [automation_tools_schema_spec.md](automation_tools_schema_spec.md).
